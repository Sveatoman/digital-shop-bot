# 💎 Digital Shop Bot

Telegram-бот для продажи цифровых товаров с автоматической выдачей.

## ✨ Основные возможности

### 🛍 Для покупателей
- **Многоуровневый каталог** товаров с фото категорий и товаров
- **Автовыдача** товаров сразу после покупки
- **Мультивалютность** — отображение в ₽ или $
- **История покупок** с доступом к ранее приобретенным товарам
- **Пополнение баланса** через CryptoBot и XRocket (USDT)

### ⚙️ Для администраторов
- **Управление каталогом** — категории, подкатегории, товары
- **Склад** — добавление позиций для автовыдачи
- **Рассылка** — текст или фото всем активным пользователям
- **Статистика** — пользователи, продажи, выручка
- **Управление пользователями** — баланс, бан/разбан
- **Автоматическое зачисление** пополнений

## 🚀 Быстрый старт

### Требования
- Python 3.11+
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))
- CryptoBot или XRocket токен (опционально)

### Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd TG\ BOT
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Настройте `.env`:
```bash
cp .env.example .env
```

4. Отредактируйте `.env`:
```env
BOT_TOKEN=your_bot_token_here
ADMIN_IDS=your_telegram_id
CRYPTOBOT_TOKEN=your_cryptobot_token  # опционально
XROCKET_TOKEN=your_xrocket_token      # опционально
```

5. Запустите бота:
```bash
python bot.py
```

## 📋 Конфигурация

### Основные параметры (.env)

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `BOT_TOKEN` | Токен бота от BotFather | **обязательно** |
| `ADMIN_IDS` | ID админов через запятую | **обязательно** |
| `DB_PATH` | Путь к базе SQLite | `shop.db` |
| `SHOP_NAME` | Название магазина | `💎 Digital Shop` |
| `MIN_DEPOSIT` | Минимальная сумма пополнения (₽) | `100` |
| `SUPPORT_URL` | Ссылка на поддержку | — |

### Курсы валют

Бот автоматически получает курс USDT/RUB из:
1. CryptoBot API (если настроен)
2. Binance (USDTRUB)
3. open.er-api.com (резерв)

```env
RATE_MODE=auto          # auto | binance | manual
USD_RATE=92.0          # резервный курс
```

## 🏗 Архитектура

```
├── bot.py              # Точка входа + фоновая проверка инвойсов
├── config.py           # Конфигурация из .env
├── db.py               # Слой БД (SQLite + aiosqlite)
├── rates.py            # Курсы валют + форматирование
├── payments.py         # CryptoBot + XRocket API
├── keyboards.py        # Клавиатуры бота
├── texts.py            # Тексты сообщений
├── httpclient.py       # Общий aiohttp-сеанс
└── handlers/
    ├── user.py         # Пользовательские хендлеры
    └── admin.py        # Админ-панель
```

### База данных

SQLite с оптимизацией производительности:
- **WAL** режим журнала
- Кэш 64MB
- Временные таблицы в памяти

Таблицы:
- `users` — покупатели
- `categories` — дерево категорий
- `products` — товары
- `product_items` — позиции для автовыдачи
- `purchases` — история покупок
- `deposits` — платежи

## 💳 Платежи

Счета выставляются в **USDT** по рыночному курсу, на баланс зачисляется **ровно указанная сумма в рублях**.

### CryptoBot

1. Создайте приложение: [@CryptoBot](https://t.me/CryptoBot) → Crypto Pay → Create App
2. Скопируйте токен в `.env`:
```env
CRYPTOBOT_TOKEN=1234:AAA...
```

### XRocket

1. Получите API-ключ в [@xRocketCryptoBot](https://t.me/xRocketCryptoBot)
2. Добавьте в `.env`:
```env
XROCKET_TOKEN=your_xrocket_token
```

## 📊 Администрирование

### Команды
- `/admin` — админ-панель
- `/cancel` — отмена текущей операции

### Функции
- **Статистика** — пользователи, продажи, выручка
- **Рассылка** — отправка сообщений всем пользователям (~25 мс/сек)
- **Категории** — создание, редактирование, фото, видимость
- **Товары** — управление ценами, описаниями, фото, складом
- **Пользователи** — поиск по ID/username, изменение баланса, бан
- **Пополнения** — история и статистика

## 🔧 Производительность

### Оптимизации
- ✅ WAL режим SQLite (параллельное чтение)
- ✅ Кэш 64MB для БД
- ✅ Пакетная проверка CryptoBot инвойсов
- ✅ Общий aiohttp-сеанс
- ✅ Рассылка с оптимизированной задержкой (25 мс/сек)
- ✅ Индексы БД на критичных полях

### Лимиты
- Проверка pending-инвойсов: каждые 20 секунд
- Скорость рассылки: ~25 сообщений/секунду
- Пагинация каталога: 6 товаров/категорий на страницу

## 🛡 Безопасность

- Защита от двойного зачисления депозитов
- Валидация всех входных данных
